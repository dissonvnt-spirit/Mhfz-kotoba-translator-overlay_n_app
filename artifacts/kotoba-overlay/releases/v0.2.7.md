# MHFZ-Z Translator Overlay v0.2.7

## Changes

- Locked game capture to horizontal Japanese dialogue blocks and removed the
  vertical-layout selector. No vertical Japanese model or automatic orientation
  recognition pass is used.
- Removed the vertical Japanese model from fresh builds and clean up obsolete
  generated copies when preparing assets.
- Updated the developer-specified target font list to MS Gothic
  (`msgothic.ttc`), Malgun Gothic (`malgun.ttf`), and SimSun (`simsun.ttc`).
  The interface explicitly identifies the recognizer as standard Japanese OCR,
  not a font-restricted or newly trained model.
- Added regression checks for horizontal-only capture, asset cleanup, and
  accurate font-target labeling to the Windows build workflow.
- Retained the Rust security dependency updates and GLib source backport from
  v0.2.6, as well as offline-first translation and optional consent-based cloud
  translation.

## Windows downloads

- `MHFZ-Z.Translator.Overlay_0.2.7_x64-setup.exe`: recommended Windows x64
  installer, including the normal Windows uninstall entry.
- `kotoba-overlay.exe`: standalone Windows x64 executable.
- `SHA256SUMS.txt`: checksums for both executable downloads.

## Updating

1. Export a dialogue-journal backup before updating.
2. Close the main app and companion overlay.
3. Install the new setup executable, or replace the standalone executable.
4. Use the dialogue-area selector to crop around horizontal NPC dialogue.

The application identity and existing model-storage location are unchanged.
Release details remain on GitHub; no in-app update checker or update notice
has been added.

## Requirements and known limitations

- Windows 10/11 x64 with Microsoft Edge WebView2 is required. Builds are
  unsigned and Windows may show a SmartScreen warning.
- Font-specific model training is deferred for future development. This release
  does not install or redistribute the three font files and does not claim
  measured font-specific speed or accuracy improvements.
- Horizontal block segmentation is not an orientation classifier: vertical
  text accidentally included in a capture could still produce incorrect output.
  Crop around horizontal dialogue rather than the entire display.
- The previous horizontal mode already loaded only the Japanese model.
  Removing the vertical model reduces bundled assets; it is not evidence of
  faster recognition compared with that previous horizontal mode.
- Two version-based moderate GLib reports may still appear for the same
  source-backported issue. The v0.2.6 security fixes and optimized regression
  gates remain in place; alerts are not suppressed.
- Offline translation requires preparing the local translation model online
  once. Optional developer-funded cloud translation requires internet and
  explicit consent; players do not provide an API key.
- This desktop release does not publish or migrate the hosted API/database.
- This is an unofficial independent companion, not affiliated with Capcom.
