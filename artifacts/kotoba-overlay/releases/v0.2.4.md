# MHFZ-Z Translator Overlay v0.2.4

## Changes

- Renamed the app from Kotoba Overlay to **MHFZ-Z Translator Overlay**, including the installer, main window, and dialogue companion window. The portable executable remains `kotoba-overlay.exe`.
- Added a hunter-inspired interface with parchment panels, bronze accents, quest-style session controls, a dialogue journal, and a matching companion overlay.
- Preserved the native application identifier, package/binary name, window labels, settings keys, and offline-model storage namespaces. This is a visible rebrand, not a new storage identity.
- On-device Japanese-to-English translation remains the default. Optional developer-funded cloud translation still requires player consent each session; no player API key is required.
- Release checks now require matching Tauri, Cargo, and Cargo.lock versions, retain historical release-note titles, and check the renamed main and companion windows during the installed-app Windows smoke test.
- Updates and update details remain exclusively on GitHub Releases. No in-app update notices, update checks, automatic downloads, or paid signing have been added.

## Windows downloads

- Recommended: `MHFZ-Z.Translator.Overlay_0.2.4_x64-setup.exe`, the Windows x64 NSIS installer.
- Portable alternative: `kotoba-overlay.exe`; Microsoft Edge WebView2 Runtime must already be installed.
- `SHA256SUMS.txt` lists SHA-256 checksums for both executables. In PowerShell, run `Get-FileHash -Algorithm SHA256 .\MHFZ-Z.Translator.Overlay_0.2.4_x64-setup.exe` (or use `kotoba-overlay.exe`) and compare the complete hash.
- The installed application targets x64 Windows, not ARM64, macOS, or Linux. The NSIS installer launcher itself may be 32-bit.

## Updating

Finish your translation session and close both the main app and its dialogue overlay. Run the new installer yourself, or replace the portable executable while it is closed. Older downloads, including v0.2.3, keep their Kotoba Overlay branding.

The rebrand retains the existing application identity and storage namespaces so it does not intentionally reset settings or downloaded models. A real Windows upgrade from the old branding has not yet been independently verified; avoid clearing application data or uninstalling with data removal. If the model is not ready, connect to the internet and choose **Prepare local model** before translating offline. Preparation requires a few hundred MB of free storage plus memory and CPU time for inference.

Cloud mode remains optional, sends recognized dialogue rather than captured frames after consent, and depends on the published developer service and remaining shared allowance. Offline mode never silently falls back to cloud. See `THIRD_PARTY_NOTICES.md` for runtime and model licenses.

## Requirements and known limitations

- Builds are unsigned. Windows may show SmartScreen warnings; signing has not been enabled.
- Microsoft Edge WebView2 Runtime is required. The installer supports WebView2 setup, but clean/offline-machine bootstrap behavior is not covered by the hosted Windows runner.
- Windows Actions checks cover silent installation, x64 application architecture, responsive renamed main and dialogue windows, always-on-top overlay rendering, reuse, closing, and reopening. They do not prove real MHFZ gameplay capture, Japanese OCR accuracy, translated-line synchronization, native offline inference after restart, or upgrade data preservation.
- Use windowed or borderless-windowed game mode; exclusive fullscreen can hide external overlays.
- OPUS-MT is a general translation model, not a game glossary. Names, specialized terms, OCR, and long dialogue can be inaccurate; local performance depends on your hardware.
- Local translation requires model preparation and retained cache storage. The browser preview needs its page loaded and is not an installed offline web app.
- Cloud translation requires internet access and is subject to shared daily allowance, rate limits, and service availability. It is not unlimited or guaranteed.
- This is an unofficial independent companion, not affiliated with or endorsed by Capcom.
