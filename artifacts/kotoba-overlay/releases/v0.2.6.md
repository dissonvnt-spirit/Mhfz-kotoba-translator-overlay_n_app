# MHFZ-Z Translator Overlay v0.2.6

## Changes

Security-maintenance release retaining the v0.2.5 capture, offline translation,
journal, archive and window-control features.

- Updated the SHA-256 dependency used by Tauri code generation to sha2 0.11.1
  and block-buffer 0.12.1. Removed the older hashing dependency from Wry's
  Android-only dependency path and examples as well.
- Backported GLib's upstream mutable-out-pointer fix for
  RUSTSEC-2024-0429 / GHSA-wrw7-89jp-8q8g without forcing incompatible GTK
  versions into Tauri.
- Replaced unmaintained proc-macro-error 1.x with proc-macro-error3
  in both GTK macro consumers.
- Added dependency/backport regression guards and an optimized Linux GLib
  iterator test gate before Windows release publication.
- Kept original upstream version numbers and licenses for the small vendored
  compatibility patches. See
  [patch provenance and scanner limitations](https://github.com/dissonvnt-spirit/Mhfz-kotoba-translator-overlay_n_app/blob/main/artifacts/kotoba-overlay/src-tauri/vendor/SECURITY-PATCHES.md).
  A scanner that checks only GLib's original version number may still report
  the advisory despite the local source backport; this is not a claim that
  upstream GLib 0.18.5 itself was repaired.
- Fresh scanning reports no critical/high findings, no static-code or
  privacy/data-flow findings, and two moderate records for the same GLib
  version-match issue despite its local backport. See the
  [remediation report](https://github.com/dissonvnt-spirit/Mhfz-kotoba-translator-overlay_n_app/blob/main/artifacts/kotoba-overlay/docs/rust-security-remediation.md).

## Windows downloads

- Recommended: `MHFZ-Z.Translator.Overlay_0.2.6_x64-setup.exe`, the Windows
  x64 NSIS installer with its standard uninstaller.
- Portable alternative: `kotoba-overlay.exe`, requiring Microsoft Edge WebView2.
- Verify downloads against the matching complete entry in `SHA256SUMS.txt`.
  Builds remain unsigned; checksum verification is not publisher signing.

## Updating

Export your journal and keep recovery receipts outside the installation before
updating. Close both app windows, then run the new installer. Application identity
and storage names remain unchanged. Do not delete your profile or offline-model
cache as a routine update step. Follow
[safe update/recovery guidance](https://github.com/dissonvnt-spirit/Mhfz-kotoba-translator-overlay_n_app/blob/main/UPDATE-RECOVERY.md)
if an older installation has a problem.

Updates remain GitHub-only: no in-app update notice or updater is included.

## Requirements and known limitations

- Windows x64 and Microsoft Edge WebView2 are required. Downloads are unsigned.
- Offline translation remains the default and needs one successful model
  preparation/download before disconnected use; there is no silent cloud fallback.
- Optional cloud translation requires explicit consent and uses the developer's
  hosted service, not a player-provided API key.
- This dependency patch release does not claim new neural OCR training,
  perfect game-font recognition or physical Windows gameplay validation.
- It does not publish or migrate the hosted API/database.
- This remains an unofficial independent companion, not affiliated with Capcom.
