# MHFZ-Z Translator Overlay v0.2.8

## Changes

- Automatic capture now waits for Japanese dialogue to remain unchanged for at
  least three seconds before making one translation attempt. Text changes
  restart the settling period.
- Unchanged dialogue is not translated repeatedly. Failed attempts no longer
  trigger the previous timed automatic retry.
- Added **Correct — save** and **Incorrect — retry** controls to both the main
  window and companion overlay. An unreviewed result remains available instead
  of being replaced by another automatically generated result.
- Correct saves the exact reviewed translation once, then allows a different
  stable dialogue page to be translated. Retry makes one explicit attempt for
  the same Japanese source using the selected engine.
- New manual and captured translations enter the journal only after approval.
  Failed, rejected, and merely successful provider responses are not auto-saved.
  Existing historical journal entries are preserved.
- The overlay requests the current review state when opened, including when a
  translation was already waiting for review. Stale or duplicate approval
  actions do not create duplicate journal entries.
- Stopping capture or changing its area discards late automatic results from
  the old source. Saving failures leave a translation pending rather than
  acknowledging it as saved.
- Increased the initial overlay height to accommodate review controls while
  preserving its move, resize, close, and content-scroll controls.
- Added timing and approval regression checks to the Windows release workflow.
  Horizontal-only OCR, the existing Rust security backports, and offline-first
  translation remain in place.

## Windows downloads

- `MHFZ-Z.Translator.Overlay_0.2.8_x64-setup.exe`: recommended Windows x64
  installer, including the normal Windows uninstall entry.
- `kotoba-overlay.exe`: standalone Windows x64 executable.
- `SHA256SUMS.txt`: checksums for both executable downloads.

## Updating

1. Export a dialogue-journal backup.
2. Close the main window and companion overlay.
3. Install the new setup executable, or replace the standalone executable.
4. Select the horizontal dialogue area. Review each result with Correct or
   Retry; only approved results will appear in the journal.

Application identity and the existing model-storage location are unchanged.
Release information stays on GitHub; no in-app update checks or notices have
been added.

## Requirements and known limitations

- Windows 10/11 x64 and Microsoft Edge WebView2 are required. Builds remain
  unsigned, and Windows may show a SmartScreen warning.
- Three seconds is a minimum OCR-text stability buffer, not a game-native
  dialogue-complete event. Polling and OCR time can make the wait longer.
- Until the player approves the current result, new dialogue does not replace
  it. Unapproved review state is temporary and is not restored after closing
  or reloading the app.
- Explicit retries may produce identical wording, particularly with the local
  offline model. Retrying does not train a model or bypass cloud quotas.
- Browser control-flow testing used synthetic dialogue and mocked OCR/provider
  responses; it does not establish physical Windows gameplay accuracy.
- Font-focused model training remains deferred. This release uses standard
  horizontal Japanese OCR, not a model restricted to the three target fonts.
- The previously documented GLib source backport and version-based scanner
  matches remain unchanged; no security alerts are suppressed.
- Offline translation requires preparing its model online once. Optional
  developer-funded cloud translation requires internet and explicit consent.
- This desktop release does not publish or migrate the hosted API/database.
- This is an unofficial independent companion, not affiliated with Capcom.
