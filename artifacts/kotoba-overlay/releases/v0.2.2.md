# Kotoba Overlay v0.2.2

## Changes

- On-device Japanese-to-English translation is now the default. OCR and translation stay on your device, with no automatic cloud fallback.
- Optional **Cloud (OpenAI)** translation is funded by the developer. Players do not need an OpenAI key or a service token. Accept the privacy prompt before sending recognized dialogue; captured frames stay local.
- Cloud allowance is shared by all players: normally 100 reserved requests per UTC day, configurable by the developer up to 1,000. Failed provider attempts also consume allowance. Each client IP is limited to five requests per minute, and each API instance allows two concurrent requests. When unavailable or exhausted, switch to offline mode.
- Local runtime and Japanese horizontal/vertical OCR resources are included. Model files are downloaded only by explicit preparation.
- Windows release checks handle both checkout line-ending conventions. Download filenames are normalized before checksum generation.
- This is the first published Windows release of both modes; the earlier v0.2.0/v0.2.1 release attempts were not distributed.
- Update information remains exclusively on GitHub Releases. The app has no update checks or notices.

## Windows downloads

- Recommended: `Kotoba.Overlay_0.2.2_x64-setup.exe`, the Windows x64 NSIS installer.
- Portable alternative: `kotoba-overlay.exe`; Microsoft Edge WebView2 Runtime must already be installed.
- `SHA256SUMS.txt` lists checksums for both downloads. In PowerShell, run `Get-FileHash -Algorithm SHA256 .\kotoba-overlay.exe` (or use the installer filename) and compare the full hash.
- These downloads target x64 Windows, not ARM64, macOS, or Linux. The installer launcher may itself be a 32-bit NSIS executable; the installed application is x64.

## Updating

Close Kotoba and its companion overlay, then run the new installer. For the portable build, replace the executable while closed. On first launch, keep the default on-device mode and, while online, choose **Prepare local model** in Session setup. Wait for preparation to finish before disconnecting. Allow a few hundred MB of disk space plus free memory and CPU time for inference.

Preparation downloads the pinned OPUS-MT Japanese-to-English model from Hugging Face and saves it in the app's local storage. It does not send game dialogue. Clearing application data, changing the app's storage origin, or losing its cache requires another download. See `THIRD_PARTY_NOTICES.md` in the source repository for model and runtime licenses.

Cloud mode is optional and must be chosen with consent again each app session. The developer's published service is preconfigured; advanced users may specify another compatible HTTPS service. No player credential is required.

## Requirements and known limitations

- Builds are unsigned. Windows may show SmartScreen warnings; code signing has not been enabled.
- Use windowed or borderless-windowed game mode. Exclusive fullscreen can hide external overlays.
- OPUS-MT is a general model, not a game glossary. OCR, names, specialized terms, and long dialogue may be inaccurate. Local inference performance depends on your hardware.
- Offline translation requires successful model preparation and retained local storage. Installed/native offline translation after a full app restart has not yet been independently verified. Automated installer, startup, and overlay smoke checks are not a gameplay or native offline-inference test.
- Cloud requires internet access, a functioning developer service, and remaining shared allowance. It is not unlimited or guaranteed to be available. Only recognized dialogue is sent to the service and OpenAI after consent.
- The browser preview needs its page loaded; it is not an offline-installed web app.
