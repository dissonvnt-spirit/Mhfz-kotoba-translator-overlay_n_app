# MHFZ-Z Translator Overlay v0.2.5

## Changes

- Added **Dialogue journal → Backups and archive** with locally saved **JSON**,
  **CSV**, or **TXT** exports. JSON/CSV files can be re-imported and merged without
  replacing existing dialogue; TXT is for reading only.
- Added optional, explicitly consented server imports: compile multiple JSON/CSV
  files into a private archive, retrieve it with a recovery code, export or merge
  the result, and delete the server copy when no longer needed.
- Added a downloadable private recovery receipt containing the code and service
  address. Codes are not automatically saved in the app: keep the receipt
  outside the installation before uninstalling. Anyone with the code can
  retrieve or delete its archive, and service operators can access stored dialogue.
- Expanded the journal from the latest 50 lines to 500 lines. At capacity,
  translation stops with an export/clear message instead of discarding old lines.
- Added [update compatibility and recovery guidance](https://github.com/dissonvnt-spirit/Mhfz-kotoba-translator-overlay_n_app/blob/main/UPDATE-RECOVERY.md):
  back up, report incompatibilities using the feedback widget or GitHub Issues,
  and consider a clean install of a fixed/future release only as a last resort.
- Updates remain GitHub-only; there is no in-app update notice or updater.
  The application identifier, storage namespaces, and binary name remain stable.

## Windows downloads

- Recommended: `MHFZ-Z.Translator.Overlay_0.2.5_x64-setup.exe` (Windows x64 NSIS).
- Portable alternative: `kotoba-overlay.exe`, requiring Microsoft Edge WebView2.
- Compare `Get-FileHash -Algorithm SHA256 .\MHFZ-Z.Translator.Overlay_0.2.5_x64-setup.exe`
  against the complete matching entry in `SHA256SUMS.txt`.

## Updating

Save a dialogue backup before updating if your version has the export feature;
older versions do not. Close both app windows, then run the installer manually.
Keep preferences/profile/cache backups if possible. Never delete user data as a
routine update step. Read the
[full recovery notice](https://github.com/dissonvnt-spirit/Mhfz-kotoba-translator-overlay_n_app/blob/main/UPDATE-RECOVERY.md)
for feedback details, safe fallback choices, and last-resort clean-install steps.

If incompatibility persists, summarize the old/new versions, Windows build,
installer names, steps, error, and affected data in the feedback widget where
available; otherwise open a GitHub issue. Do not share recovery codes, credentials,
private dialogue, or full profile folders. Wait for release-specific instructions
before clearing data or installing a future fixed version.

## Requirements and known limitations

- Windows x64 and Microsoft Edge WebView2 are required. Builds are unsigned.
- Native old-name-to-new-name installer upgrades and storage preservation remain
  **unverified**. This notice and the backup tools do not establish compatibility.
- Existing gameplay OCR/model-download/overlay-placement issues are not fixed by
  this update; a clean reinstall is not a guaranteed remedy.
- Backups preserve dialogue text and timestamps, not settings, models, cache,
  credentials, or screenshots. Previously discarded/lost lines cannot be recovered.
- JSON and CSV are importable; TXT is read-only. Limit: 500 unique lines per
  journal/compiled archive and 1 MiB per imported file/server request. Imports
  exceeding limits are rejected rather than silently truncated.
- Server archives require internet and a service running this version's archive
  API and database schema. Archive upload consent is separate from optional cloud
  translation consent. Offline export/import never automatically uploads dialogue.
- Save both local files and the private receipt. There is no account-based code
  recovery or public archive listing. Server storage/availability is not guaranteed.
- Local inference still requires preparing the model online first. Offline mode
  never silently falls back to cloud. Cloud translation remains optional and
  subject to the developer-funded service's allowance.
- This is an unofficial independent companion, not affiliated with Capcom.
