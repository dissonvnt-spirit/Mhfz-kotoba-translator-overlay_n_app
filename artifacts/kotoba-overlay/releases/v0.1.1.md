# Kotoba Overlay v0.1.1

## Changes

- Update information now lives exclusively in GitHub Releases.
- Removed the in-app update notice, automatic release checks, and update-related browser-opening command.
- Translation, capture, and the companion overlay do not depend on a GitHub update request.

## Windows downloads

- Recommended: download the Windows x64 setup executable from the assets below.
- Portable alternative: download `kotoba-overlay.exe`. Microsoft Edge WebView2 Runtime must be available.
- This release targets 64-bit Windows; it does not provide macOS or Linux installers.

## Updating

Finish your translation session, close Kotoba and its overlay, then run the new
setup executable. For a portable installation, replace the old executable while
the app is closed. Start Kotoba again and enter your translation service token.
The app does not check for, download, or install updates and does not show update
notices. Visit GitHub Releases yourself to see future changes and downloads.

## Requirements and known limitations

- A running translation API URL and its service access token are required.
  Never enter an OpenAI key in the desktop app; it belongs on the API server.
- Builds are currently unsigned. Windows may show a SmartScreen warning.
- Use windowed or borderless-windowed game mode for the external overlay.
- Real-game behavior has not been verified on a physical Windows machine.
- Automated installation/startup smoke checks are not a substitute for gameplay,
  capture, OCR, or live translation verification.
